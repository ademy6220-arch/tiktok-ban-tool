⚠️ Disclaimer: This is an experimental Rust project designed to investigate automated reporting workflows on TikTok. It is not intended as a tool for targeted harassment, intimidation, or the abuse of reporting systems.

Features
Written in Rust
Automated reporting workflow
Terminal-based interface
Configurable options
Reporting/status information
Modular Rust project structure
Responsible Use

This tool must be used exclusively for testing, research, and lawful purposes.

Specifically:

No intentionally false reports
No targeted campaigns against individuals
No harassment or intimidation
No bypassing of platform protection mechanisms
No use for manipulating moderation decisions
No use against accounts without a verifiable violation of rules

An automated report does not imply that an account has actually violated TikTok's rules. Moderation decisions rest with the platform operator. 

Platform Rules

The use of automated tools may violate a platform's terms of service or technical rules. Please familiarize yourself with the current TikTok rules before use.
