Features
 Written in Rust
 Automated reporting workflow
 Terminal-based interface
 Configurable options
 Reporting/status information
 Modular Rust project structure
Responsible Use

Das Tool darf ausschließlich im Rahmen von Tests, Forschung und rechtmäßiger Nutzung eingesetzt werden.

Insbesondere:

Keine absichtlich falschen Reports
Keine gezielten Kampagnen gegen einzelne Personen
Keine Belästigung oder Einschüchterung
Keine Umgehung von Plattform-Schutzmechanismen
Keine Verwendung zur Manipulation von Moderationsentscheidungen
Keine Nutzung gegen Accounts ohne nachvollziehbaren Regelverstoß

Ein automatisierter Report bedeutet nicht, dass ein Account tatsächlich gegen TikToks Regeln verstößt. Moderationsentscheidungen liegen beim Plattformbetreiber.

 Platform Rules

Die Nutzung automatisierter Tools kann gegen die Nutzungsbedingungen oder technischen Regeln einer Plattform verstoßen. Informiere dich vor der Verwendung über die jeweils aktuellen TikTok-Regeln.
